## Verification scope and limitations

- Browser: desktop and 390 px mobile rendering, upload of generated tones, vocal preparation, playback without automatic source selection, explicit radio selection, benchmark history, missing-model states and synthetic metric tables. No console warnings/errors captured.
- Both real-provider benchmark scaffolds were executed without model assets: three not-tested rows each, with null evaluations.
- The two model-marked tests skip without explicit configuration and authorized audio. Seed-VC/SoulX/Demucs model quality, GPU compatibility, long-input behavior and trained checkpoint quality are not established.
- MLflow is optional and local SQLite only. Its routing/logging contract is tested with a fake client; a real MLflow server/run was not used.
- Real UNMIXX, SoulX training, SVS, cloud storage and user accounts remain outside the agreed scope.
- Two deprecation warnings originate from installed FastAPI/Starlette test dependencies. No broad dependency upgrade was performed.
- The original Python environment referenced a missing interpreter. Verification used `.venv-v02`. Incomplete web dependencies were retained as `apps/web/node_modules-v01-incomplete` and rebuilt from the existing lockfile.
